# ShopIT frontend

This client uses React, Vite, React Router, TanStack Query and Redux Toolkit.

Run `npm start` from this directory for http://127.0.0.1:3000. The API must run separately on port 3002. Use `npm test -- --runInBand` for Jest and `npm run build` for the production build in build/.

See the [root README](../README.md) for environment setup, integration tests and outstanding verification work.
